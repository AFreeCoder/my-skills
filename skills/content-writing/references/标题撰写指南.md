# 标题撰写指南

核心公式（来自刘小排）：

1. **信息 = 意外** — 标题要传递出让人意外的信息
2. **用户关心什么，就把什么变成标题** — 不是你想说什么，而是读者会因为什么而点

## 灵魂拷问：找到"下周四不上课"

写标题前，先问自己：

> 这篇文章里，读者真正关心的那句话是什么？
> 对读者来说，"下周四不上课"是哪句？

不是把所有信息罗列出来（5W式），而是找到那个对读者最有杀伤力的点。

## 标题党 vs 好标题

标题党的四种套路（知道但不用）：
- 情绪放大："震惊！""笑不活了"
- 好奇缺口："竟然是他！""居然……"
- 利益承诺："干货""深度""20页"
- 稀缺紧迫："赶快看""很快删除"

**为什么不用标题党：** 短期有效但长期透支信任。我们做长期主义。

**好标题的标准：**
- ✅ 传递了真实信息（不是骗点击）
- ✅ 让读者觉得"和我有关"
- ✅ 有意外感（信息 = 意外）
- ✅ 读完标题就知道这篇文章值不值得看

## 写标题的方法

### Step 1: 先写5个候选标题
不要只想一个。写5个以上，好标题是挑出来的，不是一次写出来的。

### Step 2: 逐个检验
对每个候选标题问：
1. 读者看到这个标题，知道文章讲什么吗？→ 信息清晰
2. 读者会觉得"这和我有关"吗？→ 和读者的关系
3. 标题里有没有"意外"？→ 信息 = 意外
4. 如果去掉情绪词，标题还成立吗？→ 不依赖标题党手法

### Step 3: 选最好的那个
- 信息量最大的
- 最让人觉得"和我有关"的
- 最自然、不做作的

## 各平台标题特征

### 公众号
- 15-25字
- 可以略有悬念，但必须传递信息
- 好的："我用 Claude Code 写了一个月代码，账单吓到我了"
- 差的："震惊！这个工具竟然……"

### 知乎
- 回答无需标题（问题本身是标题）
- 专栏文章：知识感 > 情绪感
- 好的："2026年AI API价格全对比：Claude/GPT/Gemini到底花多少钱"
- 差的："你还不知道这个省钱秘诀？"

### 小红书
- ≤20字 + emoji
- 痛点 + 解决方案
- 好的："💻 Claude Code 踩坑指南｜新手少走3天弯路"
- 差的："💻 关于 Claude Code 的一些使用心得分享"

### V2EX
- 技术社区风格，朴素直接
- 好的："分享一下我用低成本跑 Claude Code 的方案"
- 差的："[干货] 程序员必看的省钱秘籍！！！"

## 反面教材速查

写完标题后快速检查，如果命中以下任何一条，重写：

- ❌ 去掉情绪词后标题没有信息量
- ❌ 读者看完标题不知道文章讲什么
- ❌ 标题和读者没有关系
- ❌ 用了"震惊""竟然""居然""必看""速看"
- ❌ 标题是一个完整的结论（没有点进去的动力）
- ❌ 标题太泛（"AI工具推荐"→ 谁都能写）
