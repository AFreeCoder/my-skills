# 审校清单

## 第一遍：内容审校

### 事实核查
- [ ] 所有数据有来源，不是编造的
- [ ] 时间、版本号、产品名称准确
- [ ] 引用的功能/特性确实存在
- [ ] 价格、折扣等数字准确

### 逻辑检查
- [ ] 前后观点不矛盾
- [ ] 因果关系成立
- [ ] 论据支撑论点
- [ ] 没有跑题段落

### 结构检查
- [ ] 开头有 hook，能吸引继续读
- [ ] 每个段落有明确主题
- [ ] 过渡自然，不生硬
- [ ] 结尾有力，不烂尾

## 第二遍：风格审校（去AI味）

### 必删套话
- "在当今…时代"
- "综上所述" / "总而言之"
- "值得注意的是" / "需要指出的是"
- "不可否认" / "众所周知"
- "随着…的发展"
- "在这个…的背景下"
- "让我们一起来看看"

### 必改句式
- "不是…而是…" 连续出现 → 拆开，换表达方式
- 被动句 → 改主动句："被广泛使用" → "很多人在用"
- "进行操作" → 直接用动词："进行分析" → "分析"
- "通过…来…" → 简化："通过优化来提升" → "优化后提升了"
- "对于…而言" → 直接说："对于开发者而言" → "开发者"

### 必改词汇
| AI 腔 | 改成 |
|--------|------|
| 显著提升 | 快了X倍 / 省了X% |
| 充分利用 | 用好 |
| 深入了解 | 搞清楚 |
| 进行优化 | 优化 |
| 相关内容 | 这些 / 这块 |
| 核心要点 | 重点 |
| 整体而言 | 总的来说 |
| 具有…的特点 | 就是… |

### 必加元素
- 抽象表达 → 具体数字："效率提升" → "每个项目省3-5小时"
- 中立客观 → 明确态度："有一定优势" → "确实比X好用"
- 通用例子 → 真实经历：编一个场景 → 用真实发生的事
- 泛化感受 → 具体细节："体验不错" → "响应速度从3秒降到0.5秒"

### 常见改写示例
❌ "在当今AI技术飞速发展的时代，编程工具也在不断进化……"
✅ "Claude Code 出了。我用了两周，确实比 Cursor 好用。"

❌ "通过充分利用Claude Code的能力，可以显著提升开发效率……"
✅ "用好 Claude Code，开发速度能快不少。我测下来，平均每个项目省3-5小时。"

❌ "该产品具有价格优势，能够满足用户的多样化需求……"
✅ "官方要 $20/月，这里 3-5 折。支持 Claude、GPT、Gemini，一个 key 搞定。"

## 第三遍：节奏打磨

### 句子长度
- 目标：15-25字为主
- 上限：不超过30字
- 方法：找出所有超30字的句子，拆成两句

### 段落长度
- 目标：手机屏幕3-5行（约50-100字）
- 超过5行的段落考虑拆分
- 单句成段可以用于强调

### 标点节奏
- 多用句号，少用逗号连接长句
- 适当用破折号做补充说明
- 省略号要有意义，不是凑字数

### 朗读测试
- 大声朗读全文
- 读起来卡顿的地方 → 改
- 读起来绕的地方 → 简化
- 读起来没重点的地方 → 加强调

### 快慢节奏
- 重要观点：短句，有力
- 展开论述：中等长度
- 背景铺垫：可以稍长
- 避免全文一个节奏
