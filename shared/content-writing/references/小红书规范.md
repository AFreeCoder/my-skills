# 小红书适配规范

## 格式要求
- 纯文本，不支持 Markdown
- 用 emoji 做视觉分隔和强调
- 短段落，每段1-3句
- 总长度：300-1000字

## 标题
- 不超过20字
- 必须带 emoji
- 用数字和痛点词
- 示例：
  - "💻 Claude Code 安装踩坑指南｜新手必看"
  - "🔥 AI API 省钱秘籍｜成本直降70%"
  - "⚡ 一个人+AI怎么搞定运营｜亲测有效"

## 正文结构
```
[hook：1-2句抓注意力]

[emoji] 小标题1
正文内容（短段落）

[emoji] 小标题2
正文内容

...

[总结/金句]
```

## 语气
- 亲切、分享感，像朋友种草
- 可以用"姐妹们""兄弟们""家人们"
- 适度口语化："绝了""真的绝""救命"
- 但技术内容保持专业度，不过度网感

## 结尾
- 引导互动："你们觉得呢？""评论区聊聊"
- 引导关注："关注我，持续分享AI干货"

## 标签（hashtag）
- 文末加3-5个相关标签
- 示例：#ClaudeCode #AI编程 #开发者工具 #省钱攻略

## 配图
- 封面图极其重要（决定点击率）
- 图文笔记推荐6-9张图
- 可以是：教程截图、对比图、流程图、数据图
- 图上加文字说明（大字、高对比度）

## CTA
- 不在正文放链接（平台限流）
- 引导到评论区或个人简介
- "链接放评论区了""看我主页"
