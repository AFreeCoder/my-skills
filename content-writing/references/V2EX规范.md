# V2EX 适配规范

## 平台特点
- 技术社区，用户质量高
- 对硬广反感，对有价值的技术内容接受度高
- 有专门的推广节点（/go/promotions）
- 社区感强，语气要自然

## 两种发帖策略

### 推广节点（/go/promotions）
- 可以直接推广，放链接
- 标题带 [内测] [推广] 标签
- 突出价格优势和技术细节
- 要诚恳，不过度包装

### 技术节点（/go/openai /go/ai /go/programmer）
- 以技术分享为主，产品为辅
- 标题是技术话题，不是广告
- 文末自然引导："如果有同样需求可以交流"
- 不要在技术节点发硬广

## 标题
- 技术向，简洁明了
- 推广帖：`[内测邀请] APIPool - 低价 AI API 中转`
- 技术帖：`分享一下我用低成本跑 Claude Code 的方案`

## 正文
- 可以用 Markdown
- 技术细节要到位（社区能看出水平）
- 语气像在论坛和同行交流
- 不要过于正式或营销感

## 引流
- 推广节点可以放链接
- 技术节点放 TG 群链接引导到群里交流
- "有兴趣的朋友可以试试，TG群：xxx"

## 红线
- 不在非推广节点发硬广
- 不短时间大量发帖
- 回帖要有实质内容
- 新号发推广容易被忽略，最好有账号历史
